# RF Toolbox Documentation

Welcome to the RF Toolbox Unity package. This guide highlights the package purpose, installation, and where to find release information.

## Overview
RF Toolbox is a personal utility library intended to streamline Unity development tasks. It bundles helpers and common utilities used across RF projects.

## Installation
1. Open Unity's **Package Manager**.
2. Choose **Add package from git URL...**.
3. Enter the repository URL for RF Toolbox and confirm.
